1. Add this to your SSH config

File location: ~/.ssh/config on Mac/Linux, C:\Users\<name>\.ssh\config on Windows.

This uses the ~/.ssh/dokku-workshop key you generated at signup. If you saved it under a different name, change both IdentityFile lines to match.

Host workshop-jump
  HostName {{ jump_public_ip }}
  User jump
  IdentityFile ~/.ssh/dokku-workshop

Host dokku-{{ user_nn }}
  HostName {{ vm_ip }}
  User dokku
  ProxyJump workshop-jump
  IdentityFile ~/.ssh/dokku-workshop

2. Test it

ssh dokku@dokku-{{ user_nn }} version

You should see a Dokku version number. If so, you're ready.

3. Cheat sheet

ssh dokku@dokku-{{ user_nn }} apps:create myapp
git remote add dokku dokku@dokku-{{ user_nn }}:myapp
git push dokku main
ssh dokku@dokku-{{ user_nn }} domains:set myapp myapp-{{ user_nn }}.{{ base_domain }}
ssh dokku@dokku-{{ user_nn }} config:set myapp BG_COLOR=tomato
ssh dokku@dokku-{{ user_nn }} logs myapp -t
ssh dokku@dokku-{{ user_nn }} scheduler:set myapp-k8s selected k3s
